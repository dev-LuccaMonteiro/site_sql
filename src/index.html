Base de Dados: academia_db

Documentação técnica da estrutura de tabelas, campos e relacionamentos.

Resumo da Estrutura

O sistema é composto por 4 tabelas principais encarregues da gestão de clientes, planos contratados, controlo de acessos (vencimentos) e fichas de treino.

1. Tabela planos

Guarda os pacotes comerciais disponíveis para venda.

Campo Tipo Chave Descrição
id_plano INT PK (Auto) Identificador único do plano.
nome VARCHAR(100) - Nome comercial (ex: Mensal, Anual).
valor DECIMAL(10,2) - Preço em euros/reais (não aceita nulo).
duracao_meses INT - Validade do plano em meses.

2. Tabela alunos

Registo dos dados pessoais e de contacto dos utilizadores.

Campo Tipo Chave Descrição
id_aluno INT PK (Auto) Identificador único do aluno.
nome VARCHAR(100) - Nome completo do aluno.
cpf VARCHAR(14) UNIQUE Documento único de identificação.
telefone VARCHAR(20) - Número de contacto.
data_cadastro DATETIME - Data e hora da criação do registo.

3. Tabela matriculas

Associa um aluno a um plano e define a validade do seu acesso.

Campo Tipo Chave Descrição
id_matricula INT PK (Auto) Identificador da matrícula.
aluno_id INT FK Aponta para alunos.id_aluno (Cascata ao apagar).
plano_id INT FK Aponta para planos.id_plano.
data_inicio DATE - Data em que a matrícula começa.
data_vencimento DATE - Data de término do contrato.
status ENUM - Estado atual: 'ativa', 'vencida' ou 'concelada'.

4. Tabela treinos

Contém os exercícios atribuídos a cada aluno.

Campo Tipo Chave Descrição
id_treino INT PK (Auto) Identificador do exercício na ficha.
id_aluno INT FK Aponta para alunos.id_aluno (Cascata ao apagar).
divisao CHAR(20) - Grupo do treino (ex: Treino A, Treino B).
exercicio VARCHAR(100) - Nome do exercício a realizar.
series INT - Quantidade de séries.
repeticoes INT - Número de repetições por série.
carga_kg DECIMAL(5,2) - Peso em quilogramas (opcional).

Relacionamentos do Sistema

1. Um Aluno pode ter várias Matrículas ao longo do tempo, mas cada matrícula refere-se a apenas um Plano.

2. Um Aluno possui vários Treinos registados na sua ficha.

3. A regra ON DELETE CASCADE garante que, ao eliminar um aluno, todas as suas matrículas e fichas de treino são apagadas automaticamente da base de dados.
